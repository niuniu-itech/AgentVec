# Ascend evidence

`paper/` holds the supplied manuscript's archived experiment records.
`source_manifest.json` maps the imported source names to SHA-256 hashes before and
after packaging. Host-specific home-directory prefixes and addresses are replaced
with placeholders; measured numbers are preserved. `paper_index.json` is a derived
index of the stable eight-operator metric suite and the 5/16 direct-generation
aggregate. The original aggregate and per-round records remain available.

The historical `vair` status was used for static admission. It is not equivalent
to the current command's VERIFIED status, which additionally requires successful
compilation and complete differential checking. Twelve registered inputs include
two triangular-solve vetoes; they must not be described as twelve successful
emitted kernels. The stable performance suite contains eight measured operators.

The archived metric suite and the naive/default/P-AIR baseline table are different
timing campaigns; rounding and observed latencies differ. Do not replace either
with inferred values from the other. The recorded direct-model results are
historical evidence, not proof that those model IDs are currently available.

New local experiments write to caller-selected external directories. Release
validation summaries, when present, describe precisely which current sources,
hardware and numerical checks were exercised. They do not overwrite the paper
records or claim to reproduce historical model decisions.
